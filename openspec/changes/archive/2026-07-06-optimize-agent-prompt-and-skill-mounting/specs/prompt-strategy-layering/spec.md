## ADDED Requirements

### Requirement: Static Prompt Layering
The system MUST support two modes for static prompt output: a `short` mode (default) emitting only core role and routing policies, and a `full` mode emitting the complete policy set. Mode selection SHALL be controlled by the `AGENT_PROMPT_LEVEL` environment variable (`short` / `full`, default `short`).

#### Scenario: Default short mode
- **WHEN** `AGENT_PROMPT_LEVEL` is unset or set to `short`
- **THEN** `buildStaticSystemPrompt()` returns only `agentRolePrompt` + `skillDiscoveryPolicy` + `extendedSkillRoutingPolicy` + `skillGeneratorPolicy`, totaling ≤ 3000 characters
- **AND** the output is sent in the user's first message (existing behavior unchanged)

#### Scenario: Explicit full mode
- **WHEN** `AGENT_PROMPT_LEVEL=full`
- **THEN** `buildStaticSystemPrompt()` returns the full 7-section policy set (current behavior preserved for rollback / debugging)

#### Scenario: Invalid level fallback
- **WHEN** `AGENT_PROMPT_LEVEL` is set to a value other than `short` or `full`
- **THEN** the system falls back to `short` and logs a warning

### Requirement: Policy Section Demotion
The system MUST demote the following policies out of the default static prompt into tool descriptions or single-line hints, so they are still enforced but not always sent in full: `taskTrackingPolicy`, `confirmationUIPolicy`, `downloadUrlPolicy`.

#### Scenario: Task tracking policy location
- **WHEN** the agent receives a user request that involves multiple sub-tasks
- **THEN** the system SHALL ensure task tracking guidance is available via `manage_tasks` tool description (not requiring it in every static prompt)

#### Scenario: Download URL policy enforcement
- **WHEN** the LLM would produce a download URL or file ID
- **THEN** the system SHALL still enforce that the value is verbatim from the current turn's tool results (enforced via output guard in agent.controller.ts, not via prompt)

### Requirement: Prompt Size Budget
The static prompt section (the part generated by `buildStaticSystemPrompt()`) MUST be ≤ 3000 characters when `AGENT_PROMPT_LEVEL=short`.

#### Scenario: Size verification
- **WHEN** the prompt is built in short mode
- **THEN** a startup log line `[Prompts] Built short prompt (chars=N)` confirms the character count is within budget
